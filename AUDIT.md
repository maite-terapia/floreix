## Sistema visual

La web conserva l'estructura del template **Love Nature by Tyler Moore**, fet que també apareix acreditat al footer públic actual. La rèplica adopta la seva geometria i estil base i els adapta al contingut actual de Floreix:

- verd principal: `#536942`
- verd secundari: `#768667`
- accent groc: `#ffd835`
- fons clar: `#f5f8f5`
- amplada principal aproximada: `1140px`
- tipografia sans lleugera, estil DM Sans
- header transparent sobre els heroes visuals i header blanc a les pàgines interiors sense cover
- botons rectangulars amb cantonades lleugerament arrodonides
- serveis en tres columnes a desktop
- canvi a una columna en mòbil

## Psicoteràpia

Rutes i elements actuals identificats:
- `Teràpia individual`
- `Un espai per cuidar el teu benestar emocional`
- `Teràpia de parella`
- `Revisar la relació per trobar noves maneres de connectar`

El crawler extern retorna timeout de manera intermitent en aquesta ruta. Per evitar substituir contingut per text inventat, la pàgina catalana inclou un carregador de contingut des de la REST API pública de WordPress de Floreix. Quan la API respon, s'utilitza directament `content.rendered` i el CSS Elementor corresponent de la pàgina actual.
